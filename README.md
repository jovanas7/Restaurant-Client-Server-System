# Restaurant Client-Server System

A desktop application for restaurant management developed using **Java**. The project is based on a **client-server architecture**, where the client communicates with the server through socket communication.

The application provides functionality for managing guests, orders, waiters, and menu items. Data is stored in a relational database, while the user interface is implemented using **Java Swing**.

## Technologies Used

- Java
- Java Swing
- Java Sockets
- MySQL/MariaDB
- SQL
- NetBeans

The project demonstrates working with client-server communication, database integration, and object-oriented programming.
